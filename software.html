03 / 05LISTEN顧客

每一戶的問題，
都值得聽完。

我們在乎每位顧客的想法和問題。動手寫程式之前，先把需求問清楚。

01想自己更新網站內容，可以嗎？

可以規劃內容後台。欣緯生醫的 CMS 就是一例：登入後撰寫文章、存草稿，再按下發佈。

02手機上看會不會跑版？

電腦版與手機版一起設計，也一起檢查。

03只有想法，還沒有設計稿。

從聊需求開始，先整理頁面架構，再進入設計。

04做得出我們品牌的感覺嗎？

先確認品牌色、字體和說話語氣，再套用到每一頁。

05網站會不會很慢？

圖片與動畫依裝置調整，離開畫面的動畫會暫停。

04 / 05WORKS網站作品03 / 07

欣緯生醫 CMS 後台

自建的內容後台，公開站與後台都放在 GitHub Pages。

後台運作原理
  1. 登入Passkey 或管理密碼，交給 Google Apps Script 後端驗證；密碼不存在後台頁面。
  2. 編寫在 CMS 撰寫、審稿、存草稿；選題頁和待審稿匣協助整理內容。
  3. 發佈Apps Script 先檢查 GitHub 目標與寫入權限，再把文章一次 commit 到公開站，最後確認 GitHub Pages 已經上線。
  4. 延伸網站上線後才寄電子報（Gmail 寄送，訂閱者存在 Google Sheet）；圖卡與貼文經 Canva、Meta 發佈。
內部系統・不對外開放
